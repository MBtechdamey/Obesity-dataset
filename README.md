# Obesity Dataset Analysis

This project explores factors associated with obesity using the **Obesity Dataset**.

### What I Did

* Cleaned and prepared the dataset
* Performed exploratory data analysis (EDA)
* Analyzed demographic, dietary, and lifestyle factors
* Created visualizations to identify patterns and relationships
* Calculated BMI and examined its relationship with obesity levels

### Key Areas Explored

* Obesity levels
* Age and gender
* Family history of overweight
* High-calorie food consumption
* Physical activity
* Vegetable consumption
* Transportation habits
* BMI and other numerical variables

### Tools

**Python | Pandas | NumPy | Matplotlib | Seaborn | Jupyter Notebook**

This project demonstrates practical skills in **data cleaning, exploratory analysis, visualization, and interpretation of health-related data**.
